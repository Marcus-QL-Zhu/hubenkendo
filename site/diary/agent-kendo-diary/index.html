同时跑五个Agent会话以后，我去练剑道

一个同时跑多个 Codex 会话的上班族，记录自己为什么在高强度用脑之后去练剑。

2026-08-09MarcusVibe Coding剑道注意力上海长宁
虎贲馆HUBEN KENDO

最近我看了一眼自己的 Codex 使用统计。累计 Token 数已经到了 131.5 亿，峰值 Token 数 10.3 亿。最长一次聊天是 23 小时 22 分。

数字看起来有点夸张。统计口径我还没有完全弄清，它们只说明一件事，得益于Tibo的反复重置额度，我过去几个月确实用得很重。

Codex 使用统计，为了把额度用完蹬到天昏地暗。

我从今年 2 月开始高强度做 Vibe Coding。平均每天四五个小时，最忙时会同时跑五个会话。工作日白天还要正常上班，而我的本职工作本身就很吃脑子。到了晚上，注意力继续在几个 Codex 会话之间来回切。

这段状态持续久了以后，我发现去练剑能把连续的用脑打断一会儿。

剑道训练一样要动脑。站到对手面前，我必须全神贯注。只要还惦记着工作，反馈通常来得很快。

我会被对手打中。

这件事甚至有点好笑。电脑里同时跑着五个会话，我可以在它们之间切来切去。练剑时没有这个余地，对手不会停下来，等我把脑子里的事情处理完。

于是我只能把工作先放下，看着眼前的人。

我很喜欢这种强制。训练时我仍然要判断和反应。我只处理眼前正在发生的动作，不再同时挂着工作和几个会话。

白天的本职工作和晚上的 Vibe Coding 经常连在一起，脑子一直处在处理问题的状态。剑道训练把这段连续用脑截开了一会儿。对我来说，这已经是很有效的减压。

工作还在那里，没跑完的会话也不会自己消失。可我已经有一段时间没有想它们了。

这是我的个人体验。剑道对别人有没有同样的作用，我不知道。对我来说，它提供的是一段很具体的专注。只要我又开始想工作，挨一下就知道了。
